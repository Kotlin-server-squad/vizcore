The loyalty service fails

fetch-loyalty-points throws an exception. Its parent, load-account-page, is a plain launch, so one failing child is enough to cancel every child still loading.

vizLaunch("fetch-loyalty-points") {
  repeat(4) { pause(3000) }
  throw demoFailure("Loyalty service answered HTTP 500")}
Key idea. A failure goes up to the parent, then down to every sibling. What already finished stays finished.
