# PR L1 · Look A · Compact IDE — Plan

**Goal:** make look A (`?look=a`) match its Tree sketch, `2026-11-06-look-switch/sketches/K-A-Compact.dc.html`, on the real session page. Presentation only: the same data, buttons and behaviour as Classic.

**Base:** `feat/look-switch` (PR #301, itself stacked on #297). Branch `feat/look-a`, worktree `../vizcore-look-a`. The PR targets `feat/look-switch`.

**Where the work lives:** `frontend/src/looks/a-compact/` (`tokens.css`, `look.test.ts`). CSS only, through the `data-look-part` hooks; no `SessionBody` slot (CSS can do every change below). One shared change: a `data-look-part="node"` hook (an attribute only) on the graph's node card, so A can flatten the card without class selectors.

**Not in this PR:** the Timeline, Problems and Story screens (Parts 7, 9, 10). Their A sketches use the same frame (a full-width header bar on the surface colour, square corners, a flat dock with a border on top), so nothing here clashes with them.

## 2. Gaps between the sketch and the page

The page shows more than the sketch (kept, styled to match):

- **The app navbar** above the page (the sketch has none). It is shared `Layout`, not a session part; it keeps its tokens.
- **The rung badge** ("Instrumented" / "Demo"), **Run / Scenario finished** and **Export** in the header. Same buttons in every look; styled like the others.
- **The main view's heading** ("What's running now" / "Everything has finished"), **Show completed** and **Maximise** in the toolbar.
- **The dock's resize handle** at its top edge (the sketch's dock does not resize).
- **The node card's ID / Job / Scope rows.** The sketch's card shows only the name, state and what it waits for; the page's card also shows these rows. Same data in every look, so they stay; the card keeps its size, which the graph's layout reserves (`NODE_WIDTH`/`NODE_HEIGHT`).
- **The graph's pan hint and zoom buttons.**

The sketch shows things the page does not have, or has differently:

- **"Timeline"** in the view switch: the page's views are Graph and List (Timeline is Part 7). Labels stay the page's.
- **The Problems tab** (Part 7, with the health API).
- **The 12 px gap between the main view and the dock**: the sketch's dock sits right under the tree. The dock's size rules count that gap (`lib/dock-layout.ts`), so it stays; with the main view on the page background and no border, the gap reads as part of the tree area and the dock's top border is the only line, as in the sketch.
- **Three Inspector columns** (identity and wait, "Created at", its events): the page's Inspector has two (D-7's order down the first column, the events in the second) and its own cards. A keeps two columns and flattens the cards.
- **Node cards 168 px wide in a wrapping row:** the page's graph lays cards out at 280×240 and scales the tree to fit. Changing that is a shared layout change, not a look.
- **The purple "waiting for children" dot** in the legend: the state bar colours come from the shared state colours; they stay.

## 3. Rules kept

- CSS only, every rule scoped to `[data-look='a']` (the shared `looks-css.test.ts` checks). No slot.
- The body's gap stays pinned to 12 px.
- No colour on the node card: its border, tint and icon colours are the shared state colours from JS.
- Keyboard focus: no rule removes an outline or ring; the dock tabs keep their focus ring, HeroUI buttons theirs.
- Inline styles on the state chips (`StateBar` sets border and background inline) are beaten with `!important` in two declarations, commented, scoped to A.
- Classic: no CSS change outside `looks/a-compact/`; the one shared edit is an attribute. Before/after pixel diff must be 0.

## 4. Tests (`a-compact/look.test.ts`)

- A's definition: id, label, trial, no slots (CSS only).
- Every `data-look-part` hook A's CSS targets exists in a component (`data-look-part="…"` in `src/`), and so does every `data-testid` it targets: a renamed hook fails the test instead of silently un-styling the look.
- A's node rules set no colour (`color`, `background*`, `border-color`, `fill`, `stroke`): the state colours stay shared.
- No rule in A removes focus (`outline: none|0`, `--tw-ring-*: 0`).
- `!important` appears only in the state-chip rules.
